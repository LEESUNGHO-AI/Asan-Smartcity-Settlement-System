# 사업비 엑셀 (원천 자료)

**여기에 파일을 올리면 나머지는 자동입니다.** 새로 입력하실 것은 없습니다.

```
source/
  JEIL/사업비.xlsx      →  기관 = 제일엔지니어링
  HOSEO/사업비.xlsx     →  기관 = 호서대학교 산학협력단
  CNI/사업비.xlsx       →  기관 = 충남연구원
  KAIST/사업비.xlsx     →  기관 = 한국과학기술원
```

폴더 이름이 곧 기관 코드입니다. 파일명은 자유롭게 쓰셔도 됩니다.

## 올리는 방법

리포지토리 → 해당 폴더 → **Add file** → **Upload files** → 드래그 → Commit

커밋되는 순간 GitHub Actions가 아래를 자동으로 처리합니다.

1. 엑셀 파싱 → `data/budget.json`, `data/evidence.json` 갱신
2. 법정 요건 검증 (R-01 ~ R-23)
3. 집행결과 제출 양식 DOCX 생성
4. 공개 대시보드 집계 갱신
5. Slack `#정산-알림` 으로 결과 통보

## 공개 저장소로 운영하는 경우

저장소가 **Public** 이면 워크플로가 자동으로 `--mask` 를 붙여 실행합니다.
급여·여비·평가위원 수당의 **개인 성명이 가려진 채로** 원장에 기록됩니다.

```
이성호 → 이*호        임혁 → 임*
```

법인·상호는 상거래 정보이므로 가리지 않습니다(㈜싸인텔레콤, 한국철도공사 등).
판단이 애매하면 **가리는 쪽**을 택합니다. 덜 가려서 실명이 새는 것보다 낫기 때문입니다.

또한 공개 저장소에서는 **집행결과 제출 양식 DOCX를 Artifact로 올리지 않습니다.**
공개 저장소의 Artifact는 누구나 내려받을 수 있기 때문입니다.
국토부 제출용 원본(실명 포함)은 아래처럼 로컬에서 만드십시오.

```bash
npm run import -- source/JEIL/사업비.xlsx --org JEIL   # --mask 없이
npm run report -- --org JEIL --from 2023-12-01 --to 2026-12-31 --status 확정,제출완료
```

저장소를 Private 으로 바꾸면 마스킹이 자동으로 해제되고 DOCX Artifact도 다시 올라옵니다.

## 엑셀에 있어야 하는 시트

| 시트 | 쓰이는 곳 | 필요한 열 |
|---|---|---|
| **총괄** | 총괄명세서의 예산집행계획(A) | 비목, 보조세목, 산출기초, 예산 |
| **지출내역** | 일자별 집행내역 · 세부집행내역 | 비목, 세목, 산출기초, 결제방법, 결제일자, 이체일자, 지급처, 내용, 공급가액, 부가세, 지출금액 |

열 이름은 위와 정확히 같아야 합니다. 순서는 달라도 되고, 다른 열이 더 있어도 무시됩니다.
비목·세목 표기는 `인건비(110)` / `보수(01)` 형식과 `인건비` / `보수` 형식 모두 인식합니다.

## 파서가 채우지 못하는 것

엑셀에 없는 항목이라 자동으로 채울 수 없습니다. 검증기가 「보완필요」로 표시합니다.

| 항목 | 처리 |
|---|---|
| 재원(국비/도비/시비) 구분 | 전부 국비로 두고 R-07이 이탈을 표시 → 재원 열을 추가하시면 자동 반영 |
| 인건비 참여율·귀속월·생년월일 | 「보완필요」 상태로 들어옴 → Google Form 또는 Notion에서 보완 |
| 사업자등록번호 | 세부집행내역에 빈칸으로 출력 → 필요 시 열 추가 |
| 계약ID | 계약대장과 수동 연결 |

**엑셀에 열을 추가하시는 게 가장 빠른 해결입니다.** `재원`, `사업자등록번호` 열을 넣어주시면
파서가 그대로 읽습니다. 열이 없어도 동작하므로 급하지 않습니다.
