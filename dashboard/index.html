사업비 엑셀 올리기

올리시면 화면에서 바로 확인하고, 그대로 GitHub에 반영합니다
여기에 사업비 엑셀을 끌어다 놓으세요 또는 눌러서 파일 선택  ·  「총괄」과 「지출내역」 시트가 있어야 합니다
GitHub 반영에는 토큰이 한 번 필요합니다 (내 브라우저에만 저장)

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 이 저장소에 Contents: Read and write 권한만 주어 발급하십시오.

집행 현황을 불러오는 중입니다.
